## Viva Q&A
1 Flask? A lightweight Python web framework. 2 HTTP? Stateless request/response protocol. 3 HTTPS? HTTP over TLS. 4 TLS certificate? Signed proof a key belongs to a hostname. 5 Chain verification? Checking signatures up to a trusted root CA. 6 HSTS? Forces browsers to use HTTPS. 7 CSP? Limits where scripts/resources load from, reducing XSS. 8 X-Content-Type-Options? nosniff stops MIME guessing. 9 X-Frame-Options? Prevents clickjacking. 10 Referrer-Policy? Controls referrer leakage. 11 Secure cookie? Sent only over HTTPS. 12 HttpOnly? Blocks JavaScript access. 13 SameSite? Limits cross-site sending (CSRF). 14 SSRF? Tricking a server into requesting internal resources. 15 How do we stop it? Validate resolved IPs, pin the connection, re-check redirects. 16 DNS? Maps names to IPs. 17 Why not scan localhost? Prevents internal-network probing. 18 Severity? Estimated impact and likelihood. 19 False positive? A flagged issue that is not real, e.g. CDN differences. 20 Limits of config auditing? Does not find code bugs, checks one request only. 21 Why parameterized SQL? Prevents SQL injection. 22 CSV injection? Cells starting with = run as formulas; we prefix a quote. 23 Risk management link? Score prioritizes remediation. 24 Why a timeout is not a finding? Failure to connect is not proof of weakness.
